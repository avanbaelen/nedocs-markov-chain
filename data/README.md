# Data

The dataset used for this project consists of non-public emergency department
operational data and is not included in this repository.

The analysis uses hourly National Emergency Department Overcrowding Score
(NEDOCS) observations collected over approximately four and a half years.
The data was used to construct and evaluate time-dependent Markov transition
models for forecasting future NEDOCS crowding states.

The source data is not distributed publicly due to data-use and privacy
considerations. The Jupyter notebook is provided to document the methodology,
model implementation, evaluation process, and resulting analysis.

## Expected Data Location

The notebook expects the source data at:

`data/Hourly_NEDOCS.csv`

The original dataset is intentionally excluded from this repository.
